# haru twitter toolbox

恢复帖子图片的浏览器原生右键菜单，方便保存、复制或分享图片（具体选项取决于浏览器）。

在 X / Twitter 的帖子分享菜单顶部添加：

- **Copy link**：复制原始链接。
- **Copy link (fx)**：复制 fxtwitter.com 链接。
- **Copy link (vx)**：复制 vxtwitter.com 链接。

支持保留图片、视频序号，以及鼠标和键盘操作。
三种复制链接都会去除跟踪参数（如 `?a=…&s=20`）。

## 安装

1. 安装 Tampermonkey（油猴）浏览器扩展。
2. 点击 [一键安装脚本](https://raw.githubusercontent.com/Antonoko/haru-twitter-toolbox/main/haru-twitter-toolbox.user.js)，在油猴页面点击「安装」。
3. 刷新 X / Twitter，打开帖子的分享菜单即可使用。

安装后支持通过油猴检查更新。
